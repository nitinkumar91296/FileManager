# FileManager

Requirements:
1. Install Sprint Tool Suite for Eclipse
2. Install MongoDB & Compass.
3. Clone the project and open with the STS application.
4. Open src/main/java -> DriveNewApplication.java file.
5. Right click in "DriveNewApplication.java file" and run as Spring application.
6. Open localhost:8080 port in the broswer and login as user created in initiateDatabase.java file.
